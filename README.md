# ABC Marketing Console — Flash Sale Prototype

A standalone React and Vite prototype for configuring, managing, and viewing Flash Sale events.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5174](http://localhost:5174).

## Build

```bash
npm run build
npm run preview
```

## Upload to GitLab

Create a blank project in GitLab, then connect this local repository to its Git URL:

```bash
git remote add origin <your-gitlab-project-url>
git push -u origin main
```

Do not initialize the GitLab project with a README if you want to push this repository as its first commit.
